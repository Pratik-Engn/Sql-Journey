# Problems Day 1

## Question 1 — Find Customer Referee

You are given a `Customer` table containing customer information.

Find the names of customers whose `referee_id` is not equal to `2`.

Customers with a `NULL` referee_id should also be included.

Return the result in any order.

## Question 2 — Big Countries

You are given a `World` table containing:

- `name` — country name
- `continent` — continent
- `area` — area of the country
- `population` — population
- `gdp` — GDP

Find the name, population, and area of countries that are considered big.

A country is considered big if:

- Its area is at least 3,000,000, OR
- Its population is at least 25,000,000.

Return the country name, population, and area.

---

## Question 3 — Article Views I

You are given a `Views` table containing:

- `article_id`
- `author_id`
- `viewer_id`
- `view_date`

Find the IDs of authors who viewed their own articles.

An author viewed their own article when `author_id` is equal to `viewer_id`.

Return the author IDs without duplicates.

Sort the result in ascending order.

---

## Question 4 — Invalid Tweets

You are given a `Tweets` table containing:

- `tweet_id`
- `content`

A tweet is considered invalid if the number of characters in its `content` is strictly greater than 15.

Find the IDs of all invalid tweets.

Return the result in any order.

## Question 8 — Count Exams Written by Each Student

You are given two tables:

### Students
- `student_id`
- `student_name`

### Examinations
- `student_id`
- `subject_id`

For every student and every subject, find the number of times the student attended/wrote that subject's exam.

Include every student-subject combination, even if the student never wrote that exam.

If a student did not write an exam for a particular subject, return `0`.

Return:

- `student_id`
- `student_name`
- `subject_id`
- `subject_name`
- `attended_exams`

Order the result by `student_id`, then `subject_id`.

## Question 11 — Average Selling Price

You are given two tables:

### Prices
- `product_id`
- `start_date`
- `end_date`
- `price`

### UnitsSold
- `product_id`
- `purchase_date`
- `units`

For each product, calculate its average selling price.

The average selling price is:

`SUM(price × units) / SUM(units)`

Only match a sale with a price when the purchase date falls between the price's start and end dates.

Round the result to 2 decimal places.

Return:

- `product_id`
- `average_price`

---

## Question 12 — Immediate Food Delivery II

You are given a `Delivery` table containing:

- `order_id`
- `customer_id`
- `order_date`
- `customer_pref_delivery_date`

For each customer, consider only their earliest order.

Find the percentage of those first orders that were delivered on the customer's preferred delivery date.

An order is considered immediate when:

`order_date = customer_pref_delivery_date`

Return the percentage rounded to 2 decimal places.

Return the column:

- `immediate_percentage`
